## ✨ 它能做什么？

### 🔍 看不懂的地方，直接问
翻到任何一页，直接在界面上提问。SlideMind 会结合当前页面内容、前后文语境，给出贴合这份 PPT 本身的解释——不是泛泛的通用回答。

### 🖼️ 框选公式或图表，精准提问
遇到复杂的数学推导、流程图或架构图？用鼠标框选任意区域，SlideMind 会针对你选中的部分进行解释。不用截图、不用描述、不用切换窗口。

### 📝 自动生成笔记草稿
阅读过程中，SlideMind 可以自动提炼当前页面的核心要点，生成 Markdown 格式的笔记草稿。你只需要在此基础上补充个人理解，而不是从零开始整理。

### 🧪 学完即练，即时巩固
对某一页或某一章节内容掌握得如何？让 SlideMind 自动生成选择题、判断题和简答题，边学边测，做完立即查看答案解析。

### 📚 复习时，抓住重点
面对数百页 PPT，SlideMind 可以帮你提炼章节结构、识别核心概念，生成结构化的复习摘要，让复习不再盲目。

## 🚀 使用流程

1. **上传 PPT** — 支持 `.pptx`、`.ppt`、`.pdf` 格式
2. **开始阅读** — 缩略图导航、翻页、书签，和普通阅读器一样
3. **随时提问** — 看不懂的地方，在聊天框输入问题
4. **框选追问** — 对公式/图表有疑问，直接画框选中
5. **生成笔记** — 让 AI 帮你提炼要点，形成笔记草稿
6. **自我检测** — 让 AI 基于当前内容出题，即时练习
7. **复习回顾** — 所有笔记、问答记录、练习结果自动保存
